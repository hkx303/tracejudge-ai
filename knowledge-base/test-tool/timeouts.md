# Test-tool timeouts and locators / 测试工具超时与定位

## English

`Element not found`, XPath parsing errors, and tool wait timeouts commonly originate in test scripts, locator strategy, or synchronization configuration. If device logs show the page loading successfully after the tool timeout, first validate the timeout threshold and page-ready signal.

## 中文

`Element not found`、XPath 解析错误和工具等待超时通常来自测试脚本、元素定位策略或同步配置。若设备日志显示页面在工具超时后继续正常加载，应优先验证超时阈值与页面就绪信号。
